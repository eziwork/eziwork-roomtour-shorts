# 룸투어 쇼츠 스타일 가이드

Instagram 「랜선집구경」 스타일 릴스(사람 없이 1인칭으로 걸으며 찍은 집 투어)를 분석한 결과다.

## 1. 화면 구성 (diary 스타일, 기본값)

| 요소 | 모양 | 위치 / 시간 |
|---|---|---|
| 인트로 상단 단어 | 영문 소문자 손글씨(`seoul`, `korea`, 동네 영문명), 분홍→라벤더 그라데이션, 흰 글로우 | 제목 위, 0.15초에 등장 |
| 인트로 제목 | 흰색 손글씨, 2~3줄, 줄당 9자 이하, 옅은 검정 그림자 | 화면 중앙, 0~3초 |
| 인트로 하단 단어 | `roomtour!` 같은 그라데이션 강조 단어 | 제목 아래, 약간 튀는 느낌으로 등장 |
| 내레이션 자막 | 흰색 손글씨, 1~2줄, 줄당 18자 이하 | 화면 정중앙, 2.2~3.2초씩 |
| 방 라벨 | `거실` / `+석재 아트월`처럼 2줄. 첫 줄이 조금 더 큼 | 그 방이 화면에 나오는 동안 |
| (선택) 영문 라벨 | `Living room`을 그라데이션으로 라벨 위에 표시 (`en` 필드). 밝은 하늘·창 위에서는 안 보이니 빼기 | 라벨과 함께 |
| (선택) 정보 배지 | `신림동 · 보증금 500 / 월세 35` 작은 흰 손글씨 한 줄 | 화면 위쪽, 인트로 이후 계속 |
| (선택) 엔딩 카드 | 마지막 프레임 정지(흐림+어둡게) 위에 매물 정보·문의 3줄 | 영상 끝에 2.5초 추가 |

레퍼런스 화면에는 화살표, 이모지 스티커, 박스 배경이 없다. 글자와 영상만 있다. 그래서 고급스럽고 담백하게 보인다. 장식을 더하고 싶어도 참는다.

화면 하단 약 20%는 인스타·쇼츠 UI(캡션, 버튼)에 가려지므로 자막을 두지 않는다. 정중앙이 안전 영역이다.

## 2. 글꼴

- **Gaegu Bold**(Google Fonts, OFL)를 쓴다. HiMelody, GamjaFlower, PoorStory, CuteFont와 실제로 렌더링해 비교했고, 레퍼런스의 둥글고 도톰한 손글씨에 가장 가까웠다. 상업용으로도 무료다.
- 자간은 -0.02em으로 둔다. Gaegu는 기본 자간이 넓어 그대로 두면 글자가 흩어져 보인다.
- 기본 크기는 제목 118px, 자막 66px, 강조 단어 96px이다(1080×1920 기준). 휴대폰에서 피드로 보는 영상이라 웹 기준보다 훨씬 크게 잡았다.

## 3. 자막 쓰는 법 (가장 중요)

레퍼런스 자막은 집을 소개하는 사람이 일기처럼 담담하게 말하는 톤이다. 광고 문구가 아니다.

**흐름**
1. 인트로 제목: `[핵심 특징]` + `[주거 유형]` + `랜선집구경`. 예: `탁 트인 단지뷰 / 아파트 / 랜선집구경`, `투룸+테라스 / 오피스텔 / 랜선집구경`
2. 첫 자막에서 인사한다: `안녕하세요 오늘은` / `[유형] 룸투어를 해보려합니다`
3. 장면마다 하나씩: 화면에 지금 보이는 공간을 라벨이나 감상으로 설명한다.
4. 마무리: `랜선집구경 끝!` / `구경해주셔서 감사합니다 :)`. 문의 안내나 매물 정보가 있으면 마지막 자막 대신 엔딩 카드(`outro`)에 넣어서 마지막 방 자막을 지킨다.

**말투 예시** (레퍼런스 원문과 이번 제작본)
- `개방감이 아주 좋았던 타입이었습니다`
- `위층에 일부가 천장 형태로 막혀있어서`
- `인프라가 잘 갖춰져 있는 곳이에요!`
- `거실이 넓게 빠져서 / 개방감이 아주 좋았어요`
- `통창 너머로 / 일몰 리버뷰가 펼쳐져요`

어미는 `~했어요 / ~예요 / ~입니다`를 섞는다. 느낌표는 영상 전체에서 한두 번만 쓴다. `ㄷㄷ`, `ㅋㅋ`, 과장 표현(`미쳤다`, `역대급`)은 이 스타일과 맞지 않는다. 그런 톤을 원하면 사용자가 따로 요청한다.

**라벨 vs 감상 자막**: 방에 처음 들어설 때는 라벨(`주방` / `+대리석 아일랜드`), 같은 공간에 머무는 동안은 감상 자막을 쓴다. 라벨만 연달아 나오면 매물 목록처럼 딱딱해지고, 감상만 나오면 어느 방인지 알 수 없다. 대략 반반이 좋다.

**사실만 쓴다** (예: 일출인지 일몰인지 모르면 `일몰` 대신 `리버뷰`, 강 이름을 모르면 `한강뷰` 대신 `리버뷰`): 가격, 평형, 지역, 층수, 신축 여부, 옵션은 사용자가 알려준 것만 쓴다. 영상만 보고 `신축`, `한강뷰`, `30평대`라고 단정하지 않는다. 화면에서 확실히 보이는 것(통창, 대리석 아일랜드, 방범창, 아트월)은 써도 된다. 부동산 영상은 허위·과장 광고 문제가 실제로 생길 수 있으니, 확실하지 않으면 `리버뷰`처럼 한 단계 일반적인 표현을 쓴다.

## 4. 타이밍

- 인트로는 2.8~3.0초. 현관이나 첫 장면 위에 깐다.
- 자막은 장면 전환에 맞춘다. 자막이 바뀌는 순간 화면도 다음 공간으로 넘어가야 한다. 1초 간격 프레임 그리드(`analysis/grid.jpg`)로 각 공간이 몇 초부터 몇 초까지 보이는지 먼저 표로 적고 나서 자막을 쓴다.
- 자막 하나는 2.2~3.2초 화면에 둔다. 1.6초 미만이면 읽을 수 없다.
- 영상 길이는 원본 그대로 쓴다. 원본이 60초를 넘으면 사용자에게 줄일지 묻는다.

## 5. 팔레트 (diary)

`palette`: `lilac`(기본, 레퍼런스), `peach`, `mint`, `butter`. 영상 색감과 어울리는 걸 고른다. 노란 장판처럼 따뜻한 화면엔 `lilac`이 오히려 잘 뜬다. 영한 방 라벨(`en`)은 어두운 배경에서만 쓴다.

## 6. 소리

- 목소리를 넣으면 원본 소리는 끈다(`volume` 기본 0). 넣지 않으면 원본 생활 소음을 그대로 둔다.
- 배경음은 `bgm.py`가 버전 분위기에 맞춰 찾아오거나, 사용자가 준 파일을 쓴다(SKILL.md 3-c). 목소리가 나올 때 자동으로 작아진다.

## 7. 버전별 말투와 화면 (vlog · quiz · luxe)

스타일은 `spec.json`의 `style`로 고른다. 화면 시안: `versions.jpg`. 세 버전 모두 글자 안에 `*단어*`로 감싼 한 단어만 포인트 색이 된다. 한 자막에 강조는 하나까지.

### vlog — 임장 브이로그

기준 자료는 `reference-vlog.md`다(자막 패턴, 역할별 장식표). 자막을 쓰기 전에 반드시 읽는다. 문장은 베끼지 않고 구성, 밀도, 장식 문법을 가져온다. "세련되게"는 장식을 빼라는 뜻이 아니다. 역할별 장식은 그대로 두고 색(팔레트 3색), 외곽선, 스티커 모양만 통일해서 마감을 깔끔하게 한다.

**자막마다 역할(`tone`)을 정한다.** 역할이 장식을 정한다. 한 영상에 최소 5종을 섞는다.

| tone | 장식 | 언제 |
|---|---|---|
| `info` | 흰 박스 + 검정 굵은 고딕(줄마다 박스) | 제목, 옵션·가전 이름 나열 |
| `say` | 흰 손글씨 + 검정 외곽선, 타이핑 | 기본 혼잣말·동선 |
| `explain` | 흰 손글씨 + 푸른 글로우, 타이핑 | 기능 설명, 걱정 해소 |
| `react` | 크고 컬러(`color`: hot/sun/pink) + 이중 외곽선, 기울임, 튀어나옴 | 감탄, 장면 전환 한 방 |
| `note` | 마스킹테이프 라벨 | 짧은 코멘트, 집주인 칭찬 |
| `ask` | 만화 말풍선 | 시청자에게 묻기 |
| `highlight` | 초록 박스 + 흰 글씨 | 구조·장점 정리 |

스티커(`sticker`): `sparkle`(반짝이) `heart` `star` `burst`(강조선) `arrow`(낙서 화살표) `none`. 자막 3개 중 1개꼴. 위치(`pos`): `top` `upper` `mid` `low` — 말하는 물건 근처, 화면 주인공을 가리지 않는 쪽. `title: true`를 준 자막 동안 제목 박스가 위에 작게 다시 뜬다(영상 중간 한 번).

**말투 — 사람 냄새 나게**
- 화자는 방 보러 다니는 사람이다. 혼잣말과 시청자에게 말 걸기를 섞고, 반말이 가끔 튀어나와도 된다(`이번엔 투룸으로 왔어!`).
- 보이는 물건 이름을 쓴다. 자막 3개 중 1개는 물건이어야 한다(`양문형 냉장고`, `붙박이장`, `중문`, `석재 아트월`, `타워형 세탁기`). "공간이 넓어요"보다 "소파 놔도 자리 남는거 보이시죠?".
- 리액션을 아끼지 않는다: `와 이 벽 뭐에요..`, `왁..`, `레전드!`(영상에 한 번), `이건 좀 반칙인데`.
- 영상마다 하나 이상: 걱정 해소(`환기 걱정은 없어요`), 쓰임새(`여기 책상 두면 딱`), 집주인 칭찬(`사장님 센스 굿`).
- 시작 훅: `~찾으시면 끝까지 보세요`, `오늘은 어디 왔게요~?`. 끝: `이런 집은 얼마일까요??`, `다음엔 어떤 집 가볼까요~`.
- 덜 다듬는다: 띄어쓰기 조금 틀려도(`남는거`, `돼있어서`), 명사로 끊어도(`고급짐`, `깔끔함!`), `..` `??` `~`를 써도 된다. 받아쓰기처럼 말한 그대로 적는다.

**AI 티 — 이렇게 쓰면 다시 쓴다**
- 귀엽게 다듬은 카피: `슬쩍 넘어가볼게요`, `자리가 이만큼 남아요`, `따로따로 있어요`, `~이 딱`을 매번 쓰기
- 두 줄이 대칭으로 딱 떨어지는 문장, 모든 자막이 `~요`로 끝나는 것
- 감각적인/돋보이는/완벽한/여유로운 일상/품격 같은 광고 단어, 쉼표 대구
- 물건 이름 없이 분위기만 말하기

**밀도**: 2~3초마다 자막이 바뀌고 화면에 자막 없는 시간이 거의 없다. 줄당 18자, 3줄까지.

**목소리**: 자막을 전부 읽지 않는다. `say`로 3~4개 자막에만 따로 말을 붙인다(자막과 같을 필요 없다). 나머지는 `"say": ""`. 자막 밀도는 목소리 때문에 줄이지 않는다.

**검수**: 스냅샷과 `references/` 기준 레퍼런스 프레임(가능하면 실제 레퍼런스 릴스)을 나란히 놓고 본다. 장식 종류 수, 물건 이름 비율, 리액션 수를 센다.

### quiz — 질문 훅 + 정보 프레임

기준 자료: `reference-quiz-luxe.md`. 가격을 맞혀 보게 하는 정보형 쇼츠다.

- **화면**: 위아래 단색 띠(기본 남색) + 가운데 영상. 위 띠의 훅 제목(`intro.lines`, 줄당 9자)은 영상 내내 고정이고, 한 단어만 노랑(`*얼마*`).
- **훅 문장**: 질문형(`○○동 원룸 / 월세 *얼마*일까요?`), 반전형(`양창인데 *반지층*?!`), 정보형(`역세권 투룸 / 요즘 *시세*`) 중 하나. `intro.bottom`은 `끝까지 보면 공개!` 같은 한 줄.
- **가격 공개**: `reveal.lines`의 숫자가 처음엔 `???`로 가려져 있다가 `reveal.at`초에 공개된다. 영상 끝 2~3초 전이 좋다. **가격은 사용자가 준 값만.** 모르면 `reveal`을 빼고 엔딩을 `가격은 댓글로`로 한다.
- **방 칩**: `room` + `tags`(화면에 보이는 것만). 장면 자막(`lines`)은 영상 전체에 2~3개, 짧게.
- **중개사무소 표시**: `agency`(상호·대표·등록번호·주소·연락처)를 사용자가 주면 아래 띠에 넣는다. 공인중개사가 매물 광고를 올릴 때 필요한 표시다. 모르면 비운다(지어내지 않는다).
- **목소리**: 남자 진행 톤이 어울린다. 공개 순간에 `say`로 "정답 공개! 보증금 오백에 월세 삼십오만 원!"처럼 숫자를 한글로 적어 읽힌다.

### luxe — 미니멀 하이엔드

기준 자료: `reference-quiz-luxe.md`. 하이엔드 매물·인테리어 쇼츠는 자막이 거의 없다.

- **표지**: 영문 이탤릭(`Room Tour`) + 명조 한 줄(`리버뷰 아파트`). 2.5~3초.
- **방 이름**: `room` + `en`(`Living`, `Kitchen`), 특징 한 단어(`lines`). 2.8초만 보이고 사라진다.
- **방 사이 문장**: 영상 전체에 2개 이하, 조용하게(`해 질 녘의 거실`). 느낌표·물결·질문 금지.
- **워터마크**: `brand`(사무소·브랜드명)와 `contact`(문의)를 오른쪽 위에 작게 영상 내내. 사용자가 준 값만.
- **엔딩**: `Private Viewing` + 문의 방법. 내레이션은 보통 넣지 않는다. 배경음은 피아노·잔잔한 곡.

### 내레이션

`tts.py`는 `say`가 있으면 그것을, 없으면 자막을 읽는다. 다음 대사가 나오기 전까지가 그 줄의 자리다. 자막 칸(2~3초)마다 말하면 넘치니 2~3칸에 한 번 말한다.
