# 레퍼런스 분석: 인스타 중개사 임장 릴스 (vlog 버전의 기준)

2026-10-10 작성. 인스타 중개사 계정의 임장 릴스 5편(원룸·투룸, 30~70초)을 프레임 단위로 읽은 기록이다. vlog 버전 자막을 쓰거나 고칠 때 이 문서를 기준으로 삼는다. 문장은 베끼지 않고 구성·밀도·장식 문법을 가져온다.

style-guide.md 7절의 vlog 규칙은 이 문서를 바탕으로 쓴 것이다. 둘이 다르면 이 문서가 우선이다.

## 1. 레퍼런스 특징

자막 원문 전체는 공개 배포본에 넣지 않았다. 아래 예시는 패턴을 보여 주는 짧은 인용이다.

### 1-2. 문체

- **화자**: 방 보러 다니는 사람. 중개사 티를 안 낸다. 반말이 섞인다(`왔어!`).
- **내용 구성**(릴스1·4의 자막 31개 기준)
  - 구체적인 물건·설비: 약 10개, 3분의 1(에어컨, 양창형 창, 풀옵션 냉장고·세탁기, 붙박이장, 화장대, 타워형 세탁기·건조기, 4도어 냉장고, 남향, 창고형 방, 큰 침대)
  - 리액션: 약 6개(`깔끔함이 묻어나네요`, `흠 잡을곳 없는 깔끔함!`, `레전드!`, `고급지네요`, `왁.. 여기 거실 보세요`, `하이라이트?`)
  - 동선: 약 5개(`들어가볼게요`, `도망쳐봅니다`, `마지막으로 거실입니다`)
  - 말 걸기·질문: 약 4개
  - 걱정 해소 2개(습기, 환기), 쓰임새 제안 2개(드레스룸·컴퓨터방, 소파), 집주인 칭찬 1~3개
- **훅과 마무리가 정해져 있다**
  - 시작: 매물 제목 카드, 또는 `~찾고 계신다면 이 영상은 끝까지 보세요`
  - 끝: `월세 얼마일까요??`로 댓글을 부르고, `다음에는 어떤 집을 가볼까요`로 다음 편을 예고한다.
- **덜 다듬은 글**: 띄어쓰기를 틀린 채 둔다(`들어갈때부터`, `흠 잡을곳`, `잘보다가`). 문장을 명사로 끊는다(`깔끔함!`, `동선이 편`). 부호를 말투대로 쓴다(`~`, `..`, `??`, `!!`).
- **길이**: 자막 하나에 평균 15자, 줄은 1~4줄, 2~4초마다 바뀐다. 화면에 자막이 없는 시간이 거의 없다.

### 1-3. 장식 (가장 큰 특징)

자막마다 장식이 다르다. 그런데 아무렇게나 다른 게 아니라, **역할에 따라 장식이 정해져 있다.**

| 역할 | 장식 | 예 |
|---|---|---|
| 제목·매물 정보 | 흰 박스(줄마다 따로) + 검정 굵은 고딕, 주변에 반짝이 | `신림역 신축 투룸 / 보증금 3천만원` |
| 기본 내레이션 | 흰 손글씨 + 검정 외곽선 | `오늘도 날이 좋아서 방 보러 나왔어요` |
| 설명 문장 | 흰 글씨 + 파랑·보라 네온 글로우 | `천장에 에어컨도 있어 습기 걱정할일 없어요` |
| 리액션·장면 전환 | 빨강·주황·노랑·분홍 큰 글씨 + 흰/검 외곽선, 가끔 기울임 | `이제 화장실로 도망쳐봅니다`, `어때요 저 잘 찍었죠` |
| 최고조 한 방 | 불꽃·이펙트 장식이 붙은 컬러 글씨 | `레전드!` |
| 짧은 코멘트 | 찢은 종이·마스킹테이프 위 검정 작은 글씨 | `사장님 센스 굿이네요`, `주방은 이렇게 동선이 편` |
| 감탄 질문 | 만화 말풍선(흰 타원, 검정 테두리) | `너무 이쁘지 않나요` |
| 정보 강조 | 단색(초록) 박스 + 흰 글씨 | `여기 사장님은 인테리어 감각이 다른것 같아요` |
| 스티커 | ✨ 반짝이, 하트, 별, 반짝 선 | 자막 3개 중 1개꼴 |

- **움직임**: 글자가 하나씩 쳐지는 타이핑 효과가 기본이다. 기울어진 글씨도 가끔 나온다.
- **위치**: 장면마다 바뀐다. 천장 에어컨을 말할 땐 위로, 바닥을 보여줄 땐 아래로 간다.
- **글꼴**: 한 영상에 손글씨 2~3종과 굵은 고딕이 섞인다.

정리하면, 장식이 "지금 이 말이 무슨 종류의 말인지"를 알려 준다. 그래서 같은 길이의 자막이어도 화면에 리듬이 생긴다.
