# Roomtour Shorts

**집 안을 걸으며 찍은 영상 하나를, 자막·목소리·배경음이 들어간 부동산 릴스로 만듭니다.**

사람 없이 1인칭으로 찍은 룸투어·매물 영상을 받아 1080×1920 세로 MP4로 만드는 Codex 스킬입니다. 영상을 장면별로 나눠 보고, 고른 버전에 맞춰 한국어 자막을 쓰고, 필요하면 AI 내레이션과 배경음까지 붙여 렌더링합니다.

**버전: 1.0.1** · **실행 환경: Codex (Claude Code에서도 동작)** · **출력: MP4 1080×1920** · **Windows · macOS**

## 4가지 버전

| 버전 | 이런 영상 | 화면 |
|---|---|---|
| `diary` 다이어리 | 담백한 「랜선집구경」 | 둥근 손글씨 감상 자막, 장식 없음 |
| `vlog` 임장 브이로그 | 방 보러 다니는 사람의 혼잣말 | 자막 역할마다 장식이 바뀜(정보 박스·외곽선 손글씨·리액션·마스킹테이프·말풍선), 스티커, 타이핑 |
| `quiz` 질문 훅 + 정보 프레임 | "이 집 월세 얼마일까요?" | 위아래 띠에 고정 훅 제목, 가격을 `???`로 가렸다가 공개, 중개사무소 표시 줄 |
| `luxe` 미니멀 하이엔드 | 고급 매물 | 자막 최소, 영문 이탤릭 표지, 짧은 방 이름, 작은 브랜드 워터마크 |

만들 때 Codex가 버전, 목소리, 배경음, 매물 정보를 먼저 물어봅니다.

## 무엇을 해 주나요?

| 단계 | 하는 일 |
|---|---|
| 영상 분석 | 1초 간격 장면표를 만들고 방마다 보이는 것을 정리 (가로 영상은 대상을 따라가며 세로로 변환) |
| 자막 | 장면 시간에 맞춰 버전별 말투로 작성. 영상에 없는 사실(신축, 평형, 한강뷰 등)과 받지 않은 가격은 쓰지 않음 |
| 목소리 (선택) | 무료 Supertonic으로 여자·남자 내레이션. 자막과 따로 2~3칸에 한 번만 말함 |
| 배경음 (선택) | 버전 분위기에 맞는 연주곡을 상업적 사용 가능한 라이선스(CC0·CC BY)에서 찾아 받음. 목소리가 나올 때 자동으로 작아짐 |
| 렌더링 | HyperFrames로 MP4 출력, 자막 잘림·대비 검사 |

## 설치

[INSTALL.md](INSTALL.md)에 Windows·macOS 순서를 정리했습니다. 요약하면:

1. 이 저장소를 Codex 스킬 폴더에 `roomtour-shorts`라는 이름으로 놓습니다.
   - Windows: `%USERPROFILE%\.codex\skills\roomtour-shorts`
   - macOS: `~/.codex/skills/roomtour-shorts`
2. 준비물을 점검합니다. 없는 프로그램은 설치 명령을 알려 줍니다.
   ```
   python scripts/doctor.py
   ```
3. 목소리를 쓸 거면 무료 음성 엔진을 한 번 설치합니다(약 550MB, API 키 없음).
   ```
   python scripts/doctor.py --install
   ```
4. Codex를 다시 엽니다.

## 사용법

Codex에서 스킬 이름과 영상 경로를 함께 입력합니다.

~~~text
$roomtour-shorts 이 매물 영상 릴스로 만들어줘: C:\Users\me\Videos\신림동원룸.mp4
~~~

질문을 건너뛰고 한 번에 정할 수도 있습니다.

~~~text
$roomtour-shorts ./빌라.mp4 릴스로 만들어줘.
버전은 quiz, 목소리는 남자, 배경음은 알아서.
신림동 원룸, 보증금 500 / 월세 35. 끝에 "문의는 DM 주세요".
~~~

결과는 작업 폴더의 `roomtour/output/`에 저장됩니다. 고칠 곳이 있으면 "3번째 자막 바꿔줘", "배경음 2번으로", "목소리 빼줘"처럼 이어서 말하면 됩니다.

설치가 잘 됐는지는 실제 영상 없이 확인할 수 있습니다. 시험 영상을 만들어 네 버전을 모두 렌더링합니다(약 1~2분).

~~~
python scripts/selftest.py
~~~

## 목소리와 배경음

**목소리**: [Supertonic](https://huggingface.co/Supertone/supertonic-3)(Supertone, OpenRAIL-M)을 내 컴퓨터에서 실행합니다. 요금과 키가 없습니다. 라이선스가 AI로 만든 콘텐츠라고 밝히도록 요구하므로, 게시할 때 본문 등에 AI 음성임을 표기하세요. 유료 Gemini 목소리도 선택할 수 있습니다(`--engine gemini`, API 키 필요).

**배경음**: [Openverse](https://openverse.org)(WordPress.org 운영) 공개 API에서 CC0·CC BY 곡만 찾습니다. 키와 가입이 없습니다. CC BY 곡은 출처 표시가 라이선스 조건이므로, 프로젝트의 `assets/bgm-credit.txt`에 남는 출처 줄을 게시물 본문에 넣으세요. 배경음 없이 만들고 인스타 앱에서 음악을 붙여도 됩니다.

## Codex에서 쓸 때

- 인터넷이 필요한 단계(처음 HyperFrames·Supertonic·배경음 받기)와 크롬을 쓰는 단계(검사·렌더링)에서 Codex가 승인을 요청할 수 있습니다. 허용하면 같은 명령을 다시 실행합니다.
- 스킬은 크롬이 막혔을 때 다른 방식으로 대충 렌더링하지 않고 승인을 요청하도록 되어 있습니다.
